03 — How it works

From input to recommendation

1

Input

The user enters two or more drug names.

2

Data

The system queries the FDA's openFDA drug label database directly for each medication's official "drug interactions" labeling text.

3

AI engine

Rule-based NLP scans each label for mentions of the other drug, then grades severity using keyword matching (contraindicated language → severe, monitoring/caution language → moderate).

4

Output

An interaction report is returned with a color-coded risk grade and a plain-language explanation.
